FEATURES IN THIS BUILD
- Responsive mobile + desktop layout.
- Main product categories and subcategory / brand filter chips.
- Mobile brand sections: Vivo, OPPO, Samsung, OnePlus, Realme, Xiaomi, Infinix, Ainova, Tecno, iPhone, Motorola.
- Fridge: Single Door / Double Door.
- Speaker: Bluetooth Speaker / JBL Party Box / Home Theatre.
- New Washing Machine and Fruit/Mixer Grinder sections.
- Product cards include Buy Now, Add to Cart, and heart-shaped Favourites.
- Favourite products appear under ☰ > My Favourites.
- Cart supports Buy This (single item), Remove (individual item), and Buy All via WhatsApp.
- WhatsApp messages are prefilled with product information; customer reviews and sends them.
- Product enquiry supports Store Pickup / Home Delivery choice.
- Customer review form with optional photo upload.

PAYMENT / SAFETY CLARIFICATION
- This website does NOT take payment directly and does NOT collect card, UPI PIN, OTP, or banking credentials.
- WhatsApp is used only for customer-initiated enquiry/order messages. The customer checks the message and taps Send.
- No automatic WhatsApp message is sent without the customer.
- This starter does not process or verify online payments. If online payment is needed later, use a reputable payment gateway with a secure backend and verified payment callbacks. Never ask customers to share OTP, UPI PIN, passwords or card PIN on WhatsApp.

PRODUCTION LIMITATIONS
- Product list, admin settings, favourites, cart and reviews currently use this browser's LocalStorage. They are not shared across devices/customers.
- For a real multi-customer shop, add server-side database, secure admin authentication, image storage, order dashboard and review moderation.
- Sample product names, prices and photos are demo data. Verify actual stock, model names, prices, warranty, offers and delivery terms before publishing.
